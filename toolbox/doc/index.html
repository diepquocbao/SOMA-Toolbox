SOMA Toolbox

An open-source MATLAB toolbox for the family of Self-Organizing Migrating Algorithms (SOMA) — one unified interface, in the style of the MATLAB Global Optimization Toolbox, for the classical variants and the modern variants by the original authors. Requires base MATLAB only (R2021a or newer); no additional toolboxes.

Quick start

opts = somaoptions('Variant','AllToOne', 'Seed',1);
[x, fval] = somamin(@(x) sum(x.^2), 10, -100, 100, opts)

See Getting Started with the SOMA Toolbox for a guided tour.

Functions

FunctionPurpose
somamin Minimize a function with a SOMA variant ([x,fval,exitflag,output] = somamin(fun,nvars,lb,ub,options))
somaoptions Create or modify a SOMA options structure; select the variant and its parameters
somaplotbestf Built-in plot function: best objective value versus migration

Defaults for every variant are the parameter values published in its reference. Any deliberate difference from the source paper is documented in DEVIATIONS.md in the repository.
